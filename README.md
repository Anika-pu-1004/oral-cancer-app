# Oral Cancer Risk Triage App (Research Prototype)

A Bengali web app that helps community health workers decide how urgently a person
should see a specialist about possible oral cancer. It combines an evidence-based
questionnaire (logistic risk model with odds ratios from published studies) with an
optional photo analysis.

**This is a research prototype, not a medical device. It does not diagnose cancer.**

Research project, Department of Mathematics, Premier University, Chattogram.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`
